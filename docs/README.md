# 포트폴리오 문서 안내

이 폴더는 각 독립 프로젝트의 소스코드를 복사하지 않고, 통합 포트폴리오에 필요한 설명·기술 분류·선별 이미지 출처를 관리합니다.

## 문서 구조

```text
docs
├─ README.md
├─ skills.md
├─ image-plan.md
├─ open-items.md
└─ projects
   ├─ industrial-kiosk-system.md
   └─ tb3-smart-factory-control-tower.md
```

## 프로젝트 문서 완성도

| 프로젝트 | README | 상세 docs | 대표 이미지 | 코드 확인 범위 | 통합 문서 상태 |
|---|---|---|---|---|---|
| Industrial Kiosk System | 정리 완료 | 8개 문서 | 7장 | Unity C# 21개 및 프로젝트 구조 | 완성형 카드 |
| TB3 Smart Factory Control Tower | 정리 완료 | 10개 문서와 근거 문서 | 공개 이미지 10장 | 로컬에는 C# 없음, 팀 통합 저장소 링크 확인 | 1차 카드, 공개 검증 보완 필요 |
| PLT Monitor | 정리 완료 | README와 상세 docs 확인 | 화면 이미지 확인 | Unity 프로젝트 확인 | 다음 작업 대상 |
| Quik Delivery | 정리 완료 | README와 상세 문서 확인 | 대표 이미지 확인 | Unity·Android 프로젝트 확인 | 개별 저장소 정리 완료 |

## 공통 작성 기준

1. 프로젝트명, 한 줄 소개, 목적, 역할, 기술, 기능, 문제 해결, 안정화, 결과 순서를 유지합니다.
2. 팀 기능과 개인 구현, 직접 구현과 외부 시스템 연동을 구분합니다.
3. 확인되지 않은 기간·팀 규모·기여도·성과 수치는 `확인 필요`로 표시합니다.
4. 프로젝트당 대표 이미지 1~3장만 복사하고 원본은 수정하거나 삭제하지 않습니다.
5. 기술명은 `skills.md`의 분류와 표기를 따릅니다.
6. 개별 저장소 README를 그대로 복사하지 않고 통합 관점에서 요약합니다.
7. 테스트 결과는 저장소 문서나 공개 근거로 확인되는 범위만 작성합니다.
