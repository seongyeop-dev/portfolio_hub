## 운영 기준

- 원본 저장소의 이미지 파일은 수정하거나 삭제하지 않습니다.
- 전체 이미지 묶음을 복사하지 않습니다.
- 얼굴, 내부 서버 주소와 비공개 정보가 포함된 화면은 사용하지 않습니다.
- 새 프로젝트 추가 시 원본·목적·대상 경로를 복사 전에 기록합니다.
