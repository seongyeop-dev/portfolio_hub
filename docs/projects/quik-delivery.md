# Quik Delivery

## 프로젝트 개요

Quik Delivery는 실제 배송 업무에서 발생하는 배송 기록, 근무시간, 수익·비용, 부가세, 월별 정산 데이터를 하나의 Android 앱에서 관리하기 위해 제작한 Unity 기반 개인 프로젝트입니다.

- **개발 기간**: 2026.05 ~ 2026.07
- **프로젝트 유형**: 개인 프로젝트
- **플랫폼**: Android
- **담당 범위**: 기획, UI 설계, 데이터 구조, 기능 구현, Android 빌드, GitHub 문서화
- **GitHub**: https://github.com/kimseongyeop2811-ux/quik-delivery

## 개발 목적

수기로 분산 관리하던 배송 기록과 근무·수익 데이터를 모바일 앱으로 통합하고, 날짜별·기간별 통계와 월별 정산 결과를 빠르게 확인할 수 있도록 구성했습니다.

단순 입력 화면에 그치지 않고 다음 운영 흐름까지 연결하는 것을 목표로 했습니다.

- 배송 및 근무 기록 저장
- 수익·비용 자동 계산
- 일별·주간·월간·연간 통계
- 달력 기반 조회
- 부가세 기록 관리
- 월별 정산
- 백업·복원
- 기존 데이터 보존을 고려한 누락 기록 보정

## 핵심 기능

### 배송 기록 관리

- 배송 날짜와 시간 기록
- 출발지·도착지 입력
- 기본요금, 부가세, 추가요금 입력
- 회사입금, 데이터사용료, 차감액, 차량전기비, 통행료 관리
- 기록 수정과 삭제
- 오늘·최근 7일·이번 달 기준 조회

### 근무시간 관리

- 근무 시작·종료
- 날짜별 근무시간 저장
- 근무 시작·종료 시간 직접 수정
- 오늘 및 월간 누적 근무시간 표시

### 통계 및 달력

- 오늘, 최근 7일, 이번 달, 올해, 전체 통계
- 항목별 합계 선택
- 날짜와 금액 범위 필터
- 월별 달력에 일별 건수·수입·지출·실수령액 표시
- 주차별 수입 막대그래프 제공

### 월별 정산

- 1월부터 12월까지 2열 카드 구성
- 배송 건수, 총수입, 회사입금, 데이터사용료, 통행료, 차량전기비, 기타 지출 표시
- 총지출과 실수령액 계산
- 이전·다음 연도 전환
- 백업 패널 표시·숨김

### 백업 및 복원

- 전체 배송·근무 데이터 JSON 백업
- 내부 백업 파일 생성
- Android 저장소로 백업 내보내기
- 파일 선택을 통한 백업 불러오기
- 백업 원본 파일은 변경하지 않고 복원된 로컬 데이터만 보정

## 기술 구조

```text
UI
└─ Manager
   └─ Repository
      └─ JsonFileService
         └─ Application.persistentDataPath
```

- **UI 계층**: 화면 표시와 사용자 입력 처리
- **Manager 계층**: 업무 규칙과 화면 간 기능 흐름 관리
- **Repository 계층**: 배송·근무·설정 데이터 접근
- **Service 계층**: JSON 저장, 수익 계산, 위치 입력 보조

## 주요 문제 해결

### 배송 0건 날짜의 고정비 누락

기존 구조에서는 배송 기록을 한 건 이상 저장한 날에만 회사입금과 데이터사용료가 포함된 일일 고정비가 생성되었습니다. 배송이 없는 날에는 기록 생성 진입점 자체가 호출되지 않아 월별 비용 데이터가 실제 운영 기준과 맞지 않았습니다.

이를 해결하기 위해 다음 방식으로 보정했습니다.

1. 2026-05-08부터 현재 날짜까지 전체 기간 확인
2. 기존 `IsDailyFixedExpense` 날짜를 `HashSet`으로 수집
3. 기록이 없는 날짜만 신규 고정비 레코드 생성
4. 기존 배송 기록은 수정·삭제·재계산하지 않음
5. 신규 기록이 존재할 때만 전체 저장을 한 번 실행
6. 앱 실행, 포커스 복귀, 날짜 변경, 백업 복원 후 동일 로직 재사용

이 방식으로 기존 사용자 기록을 보존하면서 누락 날짜만 보완하고, 반복 실행 시 중복 생성을 방지했습니다.

### 월별 정산 UI 재구성

기존 정산 화면은 단일 요약 카드 중심이어서 월별 비교가 어려웠습니다. 이를 1월부터 12월까지 항상 표시되는 2열 카드 구조로 재구성했습니다.

정산 화면만 Edit Mode 기준으로 변경하고, 홈·기록·통계·달력과 기존 런타임 UI 로직은 수정하지 않았습니다.

## 검증 결과

- Unity Console 컴파일 오류 없음
- 홈·기록·통계·정산·달력 화면 정상
- 월별 정산 12개 카드 표시 확인
- 이전·다음 연도 전환 확인
- 백업 패널 열기·닫기 확인
- 배송 0건 날짜의 고정비 생성 확인
- 기존 기록을 변경하지 않는 누락 보정 확인
- 대용량 미사용 아이콘 에셋 제거 후 UI 누락 없음
- GitHub 공개 저장소에서 개인정보·백업 JSON·APK·키스토어 제외
